## Descripción del proyecto. 

Análisis Comparativo de Datos Ante-Mortem y Post-Mortem: Identificación Cruzada de Personas Desaparecidas en Querétaro 
Este proyecto integrador de nuestra Maestría en inteligencia artificial aplicada (MNA) propone diseñar y validar un proceso de cotejo sistemático entre las fichas de búsqueda (datos ante-mortem) y el banco de datos forense de cadáveres no identificados (datos post-mortem) en el estado de Querétaro. El sistema actúa dentro del dominio de optimización y apoyo a la toma de decisiones, generando coincidencias probables para agilizar el proceso de identificación humana y brindar respuestas a las familias de personas desaparecidas. 

## Objetivo. 

Diseñar y validar un proceso de comparación entre las fichas de búsqueda y el banco de datos forense de Querétaro, que apoye la identificación de personas fallecidas.  Buscando los siguientes objetivos específicos: 
Homologar variables: estructurar y homologar los campos comparables entre los datos ante-mortem y post-mortem.  
Definir el método de cotejo: establecer los criterios y reglas de comparación entre ambos registros.  
Construir un piloto: desarrollar un prototipo de cotejo aplicado a los datos que las instituciones compartan.  
Proponer un protocolo institucional: entregar un protocolo de uso replicable para la Comisión Local de Búsqueda y la Fiscalía.
